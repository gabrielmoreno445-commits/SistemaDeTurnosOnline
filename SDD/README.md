## Estado actual

- El sitio publico funciona con Astro + Vue.
- El panel admin funciona con Vue 3 + Pinia.
- El backend funciona con Express + MySQL.
- La demo local funciona sin Docker usando `?demo=1`.
- El flujo real funciona con Docker Compose.
